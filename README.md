# NumPy Indexing and Slicing

## Data Science Internship
### VEDA Technology

## Objective

The objective of this task is to practice NumPy indexing and
slicing using the Iris Dataset.

## Dataset

Iris Dataset

The dataset contains 150 samples and 4 features:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## Topics 

- NumPy array indexing
- Positive indexing
- Negative indexing
- Row slicing
- Column slicing
- Multiple-column slicing
- Combined row and column slicing
- Step slicing

## Libraries Used

- Python
- NumPy
- Scikit-learn
- Jupyter Notebook

## Conclusion

This task helped me understand how NumPy indexing and slicing
can be used to access and process numerical data efficiently.
